# Ebenezer Opoku Boateng - Personal Developer Portfolio

A mini personal portfolio website built with semantic **HTML5**, modern **CSS3** (custom properties, Flexbox, CSS Grid, Glassmorphism), and vanilla **JavaScript (ES6+)**.

---

## 🌟 Highlights & Features

- **🌙 Dark / Light Theme Switcher**: Persisted across browser sessions using `localStorage`.
- **📱 Fully Responsive**: Optimized for ultra-wide displays, laptops, tablets, and smartphones with mobile drawer navigation.
- **⚡ Interactive Terminal Shell**: Fully interactive in-browser bash console allowing visitors to query `skills`, `projects`, `about`, `experience`, `education`, and `contact`.
- **🔍 Filterable Tech Stack & Projects**: Instant category filtering for Frontend, Backend, Tools, and Core strengths.
- **📄 Interactive Project Detail Modals**: Deep-dive project breakdowns detailing architecture, technical features, and learning outcomes.
- **📑 Printable CV / Resume Modal**: Formatted modal ready for on-screen review or instant print / PDF export (`Ctrl+P` / `window.print()`).

## 🚀 How to Run Locally

1. **Directly in your browser**:
   - Double-click `index.html` or right-click and select **Open with Chrome** (or Edge/Firefox).

2. **Using VS Code Live Server**:
   - Open this folder in VS Code.
   - Right-click `index.html` and select **"Open with Live Server"**.

3. **Using Python local HTTP server**:
   ```bash
   python -m http.server 3000
   ```
   Then open `http://localhost:3000` in your browser.

## 🌐 Deploying to GitHub Pages

1. Initialize git and commit:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of personal portfolio"
   ```
2. Create a repository on GitHub (e.g. `ebenezer-portfolio` or `<username>.github.io`).
3. Push to GitHub:
   ```bash
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git branch -M main
   git push -u origin main
   ```
4. In GitHub repository settings, go to **Pages** and choose **Deploy from a branch (main)**. Your portfolio will be live in minutes!
